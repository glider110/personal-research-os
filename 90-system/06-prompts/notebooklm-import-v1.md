# NotebookLM / 本地 Agent 结果整理约定 v1

目的：把处理结果装入 `90-system/02-schemas/processing-package.schema.json`，保留证据链，不制造缺失信息。

1. 读取用户指定的笔记本或导出文件，区分历史讨论、原始来源、工具生成报告；新提问的回答不能当作历史讨论。
2. 记录来源标题、可验证网址、发布时间、采集时间与覆盖范围；取不到原件、只看到片段或没有页码/时间戳时明确标记。
3. 保留工具草稿，独立取得原始发布稿后才能提取正式指标。摘录必须能在归档文本中定位；数值必须保留原文数字及正负转换方法。
4. 不确定的日期、模型版本不得猜测。发布时间未知填 null；模型未知填 unknown。
5. 区分累计/单月、住宅/全部房屋、金额/面积、全国/城市，避免从累计同比直接相减计算单月同比。
6. 因子、因果边和情景保持草稿；明确机制、时滞、适用范围和反证条件。不得把专家观点、估算值或 AI 引用数量当作独立事实。
7. 生成结果包后执行 validate，再 import、run、review。出现缺口时保留待核验项，不填充虚假值以通过门禁。

此模板为本地整理约定；首轮采用读取已有页面的方式，没有向 NotebookLM 发送新问题。
