# 资料提取约定（当前简版）

目标：数据源 → 指标 → 因子。不要生成因果图、情景或投资结论。

1. 只提取与指定主题相关的资料，保留原文、来源、发布日期和采集范围。
2. 提取指标名称、数值、单位、口径、地区和统计期间。逐条核对原文数字；多期数据分开保留。
3. 补充特征：主题相关性；领先/同步/滞后（相对于什么）；大众/小众（依据）；旁证/反证指标（针对什么说法）。无法判断写未知；未取得数据写缺口。
4. 先核真、按同一信息组去重，再用旁证/反证交叉核验逻辑。归纳少量底层因子，登记代表指标、排除指标及理由、核验结论。未核实数据不能作为依据，验证不足保留候选，没有依据可留空。
5. 按 `90-system/schemas/distillation-package.schema.json` 输出 2.0 包，运行 `research.py distill <package.json>`。

不把 AI 总结当原文，不把累计同比相减当单月同比，不凭空制造指标、不宣称因子已数学独立。更新数据用新包 ID，保留旧来源和旧包。
