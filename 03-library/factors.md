# 因子：从指标提炼的底层因素

因子是尽量不重复的解释维度，目前为候选提炼；“线性无关”尚未经过统计验证。

<a id="revision.82961f1a85a8d065ef975228069818219a849565244893024f2f980497fdc2fc"></a>
## 资金可得性

| 属性 | 内容 |
| --- | --- |
| 主题 | 中国房地产 |
| 底层含义 | 房企能获得多少资金，以及资金来自哪里。 |
| 代表指标 | [房企总到位资金累计同比](metrics.md#revision.eb96c07c4b328ebfd5faa71fb519cbead03d5f7336aa0c8026d92604e5d2c9a6) |
| 提炼 / 去重理由 | 总资金和贷款分项归为一个维度，不把同一资金体系拆成多个独立因素。 |
| 独立性与重叠 | 与销售回款和开发活动有关；目前只有资金流入数据，不能等同偿债能力。 |
| 状态 | 候选因子，待复核 |

### 过滤与交叉验证

| 处理 | 指标 | 理由 |
| --- | --- | --- |
| 口径对照 | [房企到位资金：国内贷款累计同比](metrics.md#revision.3ec573e2ee9d723d183afb11f99bd12bbd424b51bc23fd17af29c88d28c99e0e) | 总到位资金同比增长与贷款同比下降并存；说明结构不同，不能推出资金全面收缩。 |

原文数值已核对；总量与分项逻辑相容。均为同源统计，缺少现金与债务旁证，尚不能确认整体资金压力。

## 新增开发投入

| 属性 | 内容 |
| --- | --- |
| 主题 | 中国房地产 |
| 底层含义 | 开发商新拿地、新开工所体现的投入活动。 |
| 代表指标 | [房屋新开工面积累计同比](metrics.md#revision.f13676c2a73e532cc6e6ee66343ad726a0201feebf0067b6f3ba69d1fcf064e7) |
| 提炼 / 去重理由 | 开工绝对量和同比合并观察；拿地作旁证，施工用于区别存量项目，不重复计权。 |
| 独立性与重叠 | 受资金、需求共同影响，独立性未验证；目前不拆成拿地、开工、施工三个因子。 |
| 状态 | 候选因子，待复核 |

### 过滤与交叉验证

| 处理 | 指标 | 理由 |
| --- | --- | --- |
| 旁证 | [土地购置面积累计同比](metrics.md#revision.bd186657b823ff5916de31680b24bae812ee585c31d2eddaafaa45277740e040) | 拿地同比也下降，对新增开发活动收缩提供相关旁证；不作为第二张独立选票。 |
| 口径对照 | [房屋施工面积累计同比](metrics.md#revision.5a95bc691be8e41386bcf3be8369448da9fea6f0499a1ee38fa83025ff269fad) | 施工同比仍为正，阻止将新开工下降泛化成全部施工活动下降；存量与新增口径不同。 |
| 排除重复 | [房屋新开工面积（累计）](metrics.md#revision.84d60236b3feca78b96b3a1c3ffd2483a7a0d0c2601fce2e565b197ba2a0ad73) | 与同期间开工同比描述同一新增开发活动，主表选同比代表变化；绝对量保留备查，未重新计算同比。 |
| 排除重复 | [土地购置面积（累计）](metrics.md#revision.c54e3fcb3abc3fbf225e2c7b4cd2edfd0542d6d47b3b2fe27a2ad68e8a218507) | 与拿地同比是同一测量的不同表达，不重复计入。 |

开工与拿地方向相容，施工差异可由口径解释；同源且相互关联，只能形成候选因子，不能认定独立交叉验证已通过。

## 已实现购买需求

| 属性 | 内容 |
| --- | --- |
| 主题 | 中国房地产 |
| 底层含义 | 市场通过实际成交表现出来的购买量。 |
| 代表指标 | [商品房销售面积累计同比](metrics.md#revision.59118f6e59ca46779fa44648097aa0e89b519eedb76fb88b4faddd8f89c0b01f) |
| 提炼 / 去重理由 | 将销售作为需求的代理，不由累计同比直接推断月度趋势或潜在需求。 |
| 独立性与重叠 | 成交也受价格与供给影响，与资金维度可能重叠；仍缺价格、库存和城市数据。 |
| 状态 | 候选因子，待复核 |

### 过滤与交叉验证

暂无额外指标用于交叉核验。

只有销售面积同比这一个代理指标，交叉验证不足；缺价格、库存与城市数据，暂不能将其等同于纯粹需求变化。
